# Style Adherence Evidence

Moved from `docs/planning/evidence/style-adherence/` on 2026-04-27 as part of the retained-records migration.

Purpose: capture repeatable model-by-model evidence when evaluating AI Studio style adherence behavior.

Use this folder when:
- style prompting behavior appears inconsistent across model families,
- style system changes are introduced (prompting strategy, controls, weighting, provider routing),
- regressions are suspected after model/runtime updates.

Recommended artifact format:
- one dated markdown packet per run, for example:
  - `YYYY-MM-DD-style-adherence-run-<short-label>.md`

Starter template:
- `style-adherence-run-template.md`
