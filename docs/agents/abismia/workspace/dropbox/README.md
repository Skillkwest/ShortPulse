# Abismia Dropbox

Purpose: controlled intake area for files the user explicitly wants Abismia to inspect for UI/UX work.

## Rules

- Treat everything here as temporary intake, not durable memory.
- Do not retain raw files elsewhere unless the user asks for that and the retained copy is appropriate.
- If a durable lesson emerges, summarize it in Abismia's documented memory or retained artifact surfaces instead of treating the raw file as the long-term source of truth.
