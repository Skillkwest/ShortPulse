# Supabase Workspace

Purpose: hold the repo-local Supabase CLI config and related local temp metadata that support ShortPulse database and auth operations.

## Scope

- `config.toml`: Supabase CLI configuration for this repo.
- `.temp/`: local temp metadata generated by Supabase tooling.

## Guardrails

- This folder is an operational support surface, not the canonical home for product SQL migrations or billing/runtime truth.
- Canonical bootstrap SQL and migrations live under `sql/`.
- Follow the repo Supabase operations policy: use the Supabase CLI and do not use Docker-based local Supabase workflows.
- Treat temp files here as non-authoritative scratch artifacts.
