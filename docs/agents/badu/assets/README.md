# Badu Assets

Purpose: safe storage guidance for Badu-owned source assets and bookkeeping intake files.

This folder may hold non-sensitive:

- billing screenshots,
- redacted invoice exports,
- redacted receipt exports,
- CSV/TSV source exports,
- screenshots of provider billing tables.

Rules:

- Prefer redacted or summarized evidence when possible.
- Do not store secrets, cookies, auth tokens, API keys, raw provider credentials, card details, customer payment data, or full tax/legal filings.
- Label files with provider and date when retained.
- If retention risk is unclear, keep the evidence outside the repo and record only a source note in Badu memory or a retained report.
