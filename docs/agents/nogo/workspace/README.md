# Nogo Workspace

Purpose: Nogo-owned intake and scratch workspace for provider spend analysis.

Use this folder for:

- user-supplied billing screenshots,
- temporary CSV exports,
- scratch calculations,
- draft reports,
- provider dashboard notes.

Do not treat this folder as source of truth. Source of truth comes from current provider dashboards, official provider docs, ShortPulse billing/admin telemetry, and canonical repo pricing/model files.

Do not store secrets, API keys, customer payment details, or raw provider credentials here.
