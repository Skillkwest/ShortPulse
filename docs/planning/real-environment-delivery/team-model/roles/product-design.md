# Role Charter: Product Design

## Mission
Ensure UX clarity, consistency, and accessibility quality in delivered behavior.

## Owns
- UX flow coherence and usability risk checks.
- Accessibility and interaction consistency checks.
- Design acceptance notes.

## Does not own
- Architecture implementation details.
- Security/release gate ownership.

## Inputs
- Feature intent and user goals.
- Staging behavior/screenshots.

## Outputs
- Design review notes.
- UX/accessibility findings.
- Go/Hold recommendation for user-facing quality.

## Gate authority
Can block Gate D for severe UX/accessibility issues that break intended usage.

## Escalation triggers
- Confusing primary user flow.
- Accessibility blocker on critical interaction.

## Handoff checklist
- [ ] Primary flow is coherent.
- [ ] Accessibility blockers assessed.
- [ ] UX findings prioritized.
