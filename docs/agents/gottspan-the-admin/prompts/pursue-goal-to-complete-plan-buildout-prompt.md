# Pursue Goal to Complete Plan Buildout Prompt

Use this prompt when an agent should confidently work through an existing plan without needing the user to approve every step.

## Prompt

```text
Pursue the goal of completing the current plan's buildout. First, identify and include the actual plan document or plan source in the goal prompt, preferably as a repo path or named source, so every checkpoint can reference the same plan instead of memory. Then restate the plan's objective, source of truth, owner/lane, approved scope, proof requirements, and stop condition in your own words. If the plan document/source, objective, scope, proof requirements, or stop condition are missing, contradictory, stale, unsafe, or too vague for autonomous work, stop before implementation and tighten the goal prompt or plan until you can work safely and confidently. Once the goal is clear, work autonomously through the plan in validated batches: choose the next highest-ROI in-scope step, implement the canonical source fix or required durable update, validate the touched surface, audit your work for misses or drift, then decide the next in-scope step. Continue this loop only while the next step clearly belongs to the active plan and improves completion. Do not change UI, UX, intended behavior, launch posture, security posture, branch policy, commit/push/deploy state, or another agent's workspace unless that scope is explicitly approved in the current thread. Do not add workarounds, fallback paths, backup implementations, duplicate authorities, broad refactors, adjacent cleanup, or extra paperwork that does not directly complete the plan. Stop immediately when the plan is complete, when the next step is outside scope or belongs to another owner, when the plan itself proves incomplete or unsafe, when required proof depends on release/production/commit/push/deploy work outside your lane, when validation blocks further safe progress, or when the remaining work would mostly create churn. Close out by saying what is complete, what proof exists, what remains unproven, and the exact boundary if anything is deferred.
```
