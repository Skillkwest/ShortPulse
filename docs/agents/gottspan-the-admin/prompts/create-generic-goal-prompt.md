# Create Generic Goal Prompt

Create a compact goal prompt that will carry the active agent through the rest of the current plan correctly. The goal prompt must preserve the existing task scope, use current repo truth instead of stale memory, and tell the agent to work through validated checkpoints: at each checkpoint, audit the completed work, identify anything missed, decide the next highest-ROI in-scope step, and continue only when that next step still belongs to the active plan. The prompt must explicitly forbid UI, UX, intended functionality, and behavior changes unless the user has separately approved that scope in the current thread. It must also prevent drift into adjacent cleanup, new lanes, release work, commits, pushes, deploys, broad refactors, or paperwork that does not preserve durable truth. Require a well-defined stop condition: stop when the plan is complete, when the next step requires user approval or an out-of-scope owner, when validation/proof is blocked by release or production operations outside the agent's lane, when further work would mostly create churn, or when the next highest-ROI decision is simply to report the boundary and wait. Keep the final goal prompt as one compact paragraph under 4,000 characters.
