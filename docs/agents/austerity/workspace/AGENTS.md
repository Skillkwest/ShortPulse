# Austerity Workspace Instructions

Scope: `docs/agents/austerity/workspace/`

Inherit the root `AGENTS.md`, `docs/AGENTS.md`, and canonical Austerity instructions at `docs/agents/austerity/AGENTS.md`.

## Authority

This is Austerity's local working area for legal-policy intake and drafts. It is not final legal policy, not counsel signoff, and not the canonical source of public customer commitments.

## Workspace Rules

- Mark drafts clearly.
- Use `dropbox/` only for user-provided material that Austerity is explicitly asked to inspect.
- Use `drafts/` only for temporary working material.
- Do not retain raw secrets, payment details, customer-private exports, privileged legal material, or unredacted legal correspondence unless the user explicitly directs safe retention.
- If a user-provided file appears privileged or confidential, minimize copying, summarize only what is necessary, and ask before durable retention.
- Promote durable sanitized findings to `docs/agents/austerity/artifacts/` or `docs/agents/austerity/memory.md` when appropriate.
- Delete temporary scratch material when no longer needed.

## Validation

Before staging Austerity workspace files, check that no file contains raw secrets, payment details, customer-private exports, or unapproved public-policy text that could be mistaken for final policy.
