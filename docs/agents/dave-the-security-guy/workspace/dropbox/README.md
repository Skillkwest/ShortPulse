# Dave Dropbox

Purpose: intake area for files the user explicitly wants Dave the Security Guy to review.

## Rules

- Do not store secrets, live tokens, service-role keys, `.env` files, raw customer exports, or credential screenshots here.
- Redact sensitive values before placing security evidence in this folder.
- Promote only sanitized durable findings into `docs/agents/dave-the-security-guy/` or `docs/records/artifacts/agent/dave-the-security-guy/`.
- Remove temporary inputs when the security review or incident is closed.
