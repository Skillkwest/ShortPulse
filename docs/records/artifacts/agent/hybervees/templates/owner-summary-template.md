# Hybervees Owner Summary Template

Purpose: simple owner-facing summary format for Hybervees tester-report reviews.

## Short Version

State the main tester outcome in 2-5 short sentences.

## What This Means

Explain the product meaning in plain language.

Focus on trust, confusion, value, spend readiness, runtime continuity, or support risk.

## Do This

Name the exact next action.

If a backlog item is needed, say what the backlog item should accomplish.

Keep caveats, owner routing, lane assignment, `Do Not Overreact`, `Best Next Owner`, and "what not to overreact to" sections out of the owner summary unless the user explicitly asks for them.
