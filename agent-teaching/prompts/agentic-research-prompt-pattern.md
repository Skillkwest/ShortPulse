# Agentic Research Prompt Pattern

Purpose: research current best practices and turn the findings into repo improvements.

Use this when the agent needs fresh external research before you revise training, SOPs, or repo rules.

## Prompt Sequence

```text
Use sub-agents to research the current best practices on training codex agents to work in a local repo.
```

```text
Continue to research the current agentic best practices from <today's date>
```

```text
Synthesize and organize this data in the repo correctly.
```

```text
How can we utilize this data to help <agent's name> perform it's task correctly? Read through the data and SOPs. Do we need any top level AGENTS.md instructions? How can we adjust our approach to training <agent's name>? If you could do anything to revise our workflows and organize this repo what would you do?
```

```text
Anything else?
```

```text
Anything else?
```

Then:

```text
Go ahead and make all changes you need to.
```

## Use This Pattern For

- training system upgrades
- maintenance research
- prompt-pattern research
- SOP hardening
- repo governance revisions after new evidence
