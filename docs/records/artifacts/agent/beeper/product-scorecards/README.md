## Scope

These files rate:

- route clarity
- workflow completion quality
- trust and confidence
- continuity and persistence
- UI polish
- failure recovery
- product-wide issue severity

## Rule

- Update these files from substantive runs, not from process-only maintenance.
- Product scoring should stay evidence-backed and confidence-labeled.
