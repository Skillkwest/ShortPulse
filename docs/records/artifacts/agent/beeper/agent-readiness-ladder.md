# Beeper Agent Readiness Ladder

Purpose: define the progression model for teaching Beeper harder and more complex work over time.

## Level 1. Supervised

Can:

- follow SOPs
- log artifacts
- validate single routes
- write basic handoffs

Needs:

- explicit trainer review
- strong route selection discipline

## Level 2. Workflow Tester

Can:

- validate full route bundles
- capture believable user friction
- distinguish healthy passes from real failures

Needs:

- stronger continuity coverage
- more consistent retest closure

## Level 3. Alpha Tester

Can:

- run deep workflow bundles
- validate persistence, continuity, and reentry
- isolate trust-breaking moments cleanly
- produce useful product and engineering data in the same run

Needs:

- stronger campaign breadth
- stronger fix-retest rhythm

## Level 4. Comparative Tester

Can:

- coordinate Beeper and Bopper lanes
- compare naive-user truth against alpha-truth
- synthesize route-level differences

Needs:

- reliable multi-lane orchestration

## Level 5. Audit Lead

Can:

- own a broader product audit campaign
- prioritize route coverage and retest debt
- produce stable scorecards and quality narratives over time

## Promotion Rules

Promote only when the evidence shows:

- repeated strong run scores
- honest fidelity labeling
- continuity-ready lanes tested deeply
- retest debt reduced
- useful handoffs and product scores staying reliable

## Current Read

- Beeper currently operates between `Level 2` and early `Level 3`.
- The next promotion proof is stronger continuity-heavy coverage plus better retest closure.
