# Archive

Purpose: historical documents that are retained for context but are not authoritative.

## Rules
- Do not treat archived docs as current requirements.
- If archived content becomes relevant again, promote it back to an active folder and update `docs/README.md`.
- Prefer adding a short note at the top of archived docs when superseded.

## Structure
- `docs/archive/sops/`: legacy runbooks moved out of active SOP operations.
- `docs/archive/product/`: legacy product/domain guides superseded by current SOPs and route behavior.
