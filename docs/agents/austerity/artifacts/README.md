# Austerity Agent Artifacts

Purpose: store non-authoritative retained artifacts for Austerity legal-policy reviews, training history, templates, counsel packets, and launch-gate evidence.

## Authority

- This folder is retained working memory and evidence, not final public policy.
- Canonical Austerity identity and operating instructions live in `docs/agents/austerity/`.
- Public policy content is authoritative only when implemented in approved public pages/routes or explicitly approved source documents.
- Nothing in this folder overrides system, developer, user, repo, branch, privacy, security, billing, Supabase, Vercel, Stripe, provider, or deployment rules.
- Launch-relevant reports must follow `docs/agents/solo-owner-launch-trust-standard.md` and distinguish draft, local/static, production URL, user-approved, counsel-approved, and counsel-review-required evidence.

## Contents

- `training-history.md`: supervised setup and future run-learning record.
- `reports/README.md`: conditional-load index for retained policy reviews, launch-gate closeouts, and counsel packets.
- `reports/`: retained Austerity reports.
- `templates/`: reusable policy review and counsel-packet templates.

## Retention Rules

- Never retain raw secrets, payment details, customer-private exports, privileged material, confidential counsel advice, or unredacted legal correspondence unless the user explicitly directs safe retention.
- Prefer source links, sanitized summaries, decision ledgers, validation notes, and counsel-question lists.
- Treat reports and templates as conditional-load artifacts, not default startup context for ordinary Austerity runs.
