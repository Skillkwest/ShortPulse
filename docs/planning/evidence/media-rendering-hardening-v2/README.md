# Evidence Index: Media Rendering Hardening v2

Store slice evidence packets for this program in this directory.

## Naming Contract
Use:
`YYYY-MM-DD-<slice-id>-evidence.md`

Examples:
1. `2026-03-16-MRH2-P0-001-evidence.md`
2. `2026-03-21-MRH2-P1-001-evidence.md`

## Required Packet Contents
1. scope and contract lock summary,
2. commands executed and outcomes,
3. targeted seam test evidence,
4. full gate evidence,
5. before/after metrics and behavior notes,
6. risks and rollback notes,
7. follow-ups with owner/date.
