# Latency Workspace

Purpose: provide Latency a temporary workspace for active intake, scratch notes, draft reports, and in-progress investigation material.

This folder is not source of truth.

## Rules

- Keep durable instructions in `docs/agents/latency/`.
- Keep retained run artifacts in `docs/records/artifacts/agent/latency/`.
- Use this workspace only for temporary working material.
- Do not store secrets, tokens, raw customer data, or unfiltered logs.
- Delete or promote scratch material when it becomes obsolete or durable.

## Canonical Entry Points

- Agent contract: `docs/agents/latency/README.md`
- Local instructions: `docs/agents/latency/AGENTS.md`
- Job description: `docs/agents/latency/job-description.md`
- Active goal prompt: `docs/agents/latency/goal-prompt.md`
- Memory: `docs/agents/latency/memory.md`
- Standing SOP: `docs/agents/latency/standard-operating-procedure.md`
- Ownership manifest: `docs/agents/latency/ownership-manifest.md`
