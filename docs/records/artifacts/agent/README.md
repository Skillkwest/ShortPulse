# Agent Artifacts

Moved from `docs/planning/evidence/agent/` on 2026-04-27 as part of the retained-records evidence/artifacts split.

This folder stores non-authoritative retained agent artifacts: memory, reports, templates, KPIs, and training data.

## Layout Convention

Each agent artifact area may contain some subset of:

- `README.md`
- `memory.md`
- `baseline-kpi.md`
- `training-history.md`
- `run-log.md`
- `tools.md`
- `reports/`
- `templates/`

Not every agent needs every file.
