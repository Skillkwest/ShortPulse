# Badu Workspace

Purpose: Badu-owned intake and scratch workspace for accounting imports.

Use this folder for:

- scratch calculations,
- draft import TSV blocks,
- source-review notes,
- temporary provider import plans,
- non-sensitive user-provided bookkeeping intake material.

Do not treat this folder as source of truth. Source of truth comes from current provider billing pages, official invoices/receipts/exports, the active accounting workbook, and current user instructions.

Do not store secrets, API keys, cookies, raw provider credentials, full card numbers, customer payment data, or tax/legal filings here.
