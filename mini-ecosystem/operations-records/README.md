# Operations Records

Purpose: store real execution records produced while operating the Mini Ecosystem on actual repository work.

## Allowed content
- Actual gate decision packets (`A-E`) for real feature work.
- Actual role handoff packets for real audits.
- Actual escalation/decision notes tied to real repository changes.

## Not allowed
- Simulations
- Rehearsal scenarios
- Fabricated records

## Naming convention
- `YYYY-MM-DD-<scope>-gate-packet.md`
- `YYYY-MM-DD-<scope>-audit-packet.md`
- `YYYY-MM-DD-<scope>-escalation-note.md`
