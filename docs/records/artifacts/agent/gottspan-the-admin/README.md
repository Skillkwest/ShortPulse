# Gottspan Agent Artifacts

Purpose: store non-authoritative retained artifacts for Gottspan The Admin's repo-stewardship work.

## Status

Gottspan has a durable contract, repo-visible memory, standing SOP, retained artifact area, and local report index.

This artifact area is for training continuity, run notes, and future stewardship helpers that are too detailed for repo-visible memory but still worth keeping.

These artifact files are retained reference surfaces, not default runtime context.

## Artifact Layout

- `baseline-kpi.md`: frozen or provisional baseline for Gottspan's own repo-steward performance
- `training-history.md`: supervised pivot and future training runs
- local report template lives under `docs/agents/gottspan-the-admin/reports/run-report-template.md`
- weekly recurring report template lives under `docs/agents/gottspan-the-admin/reports/weekly-repo-state-report-template.md`

Do not add new retained artifact surfaces speculatively. Add them only after repeated use justifies a durable file that cannot live cleanly in the contract, SOP, local reports index, or the two retained files above.

## Authority

These artifacts support training, traceability, and workflow continuity. They do not override canonical repo rules, SOPs, ADRs, current code, direct validation evidence, or current user instructions.

Load them only when the task is explicitly about training continuity, KPI comparison, or retained historical evidence.
