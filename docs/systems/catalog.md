# Systems Catalog

Purpose: provide the authoritative current-state system registry and ship-readiness control surface for ShortPulse.

Notes:

- `System` is the rated unit.
- `Primary surfaces` lists user-facing surfaces or views; it does not redefine the system boundary.
- `Related operator systems` links broader systems to relevant `docs/operator-map.md` rows when they exist.
- `Ship status` compares `Current score (/10)` to the current `Ship floor`.
- `Priority band` expresses execution urgency, not system maturity.
- `Active lane` names the current handoff lane id or `queue-only` when the row is only tracked in the queue.
- `Review basis` names the audit mode or snapshot behind the row.
