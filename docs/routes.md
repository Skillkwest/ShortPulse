# Routes Map

Reference for pages, auth expectations, and ownership.

Auth required legend:

- `Yes`: protected by shared frontend/API runtime auth guards.
- `Route`: authenticated inside the route handler instead of the shared runtime auth prefix lists.
- `No`: public route or non-user auth path (for example cron-secret or internal secret protection).

| `/ai-studio`                   | Yes           | Creative canvas (prompt/image/video)                         | `/creator-studio` forwards here. When `?projectId=<uuid>` is present, AI Studio resolves the owned project record before restore continues, fails closed on invalid or cross-user project ids, treats the visible Media Library project title as `projects.title` authority instead of session-local title state, and loads/saves the current snapshot envelope through `/api/projects/[projectId]/workspace` instead of the legacy remote `sid` snapshot route. Project routes also suppress browser-global workflow-settings, legacy chat-mode, and selected-character local-storage persistence so the project workspace snapshot becomes the restore authority for the current session-snapshot envelope; broader live generated-output authority cleanup remains a later migration phase. Expert Edit is now the only Edit workflow surface. The generic Canvas workspace is no longer exposed as a primary AI Studio toolbar workflow, but the top-right header now provides independent `Canvas`, `Quick Slot Inventory`, and `Reference Grid` toggles across the four primary workflows (`Create`, `Edit`, `Video`, `Sound`), so any combination of those three right-rail surfaces can be shown or hidden, including `none`. Double-clicking one of those header toggles enters an isolate mode for that surface only, and clicking the same toggle again or the eye restore control returns to the prior panel combination. The Canvas section defaults off on first load, and Media Library folder canvases remain separate secondary surfaces. The Standard/Inpaint/Markup selector row is always available, Markup submissions are locked to the dedicated Pulse Markup v1 model, Markup submissions attach the flattened-strokes secondary reference whenever strokes exist, and the collapsed `Tools` control keeps the inline expand/collapse path instead of auto-opening the expanded Markup modal. Create `Pulse` mode now mounts an interactive left-rail Pulse Presets card with pinned preset chips, drag/drop from a `More Presets` popup, and a merged catalog surface composed of the admin-owned built-in guided-workflow set plus per-user custom Pulses from the `Pulses` section inside `Libraries -> Presets`. Custom Pulse records persist the minimal saved-instructions contract (`presetId`, `label`, `systemInstructions`, optional `description`, `pulseKind`, `createdAt`, `schemaVersion`). Built-ins stay on the guided workflow compatibility path, while custom user-authored Pulses default to the standalone `custom_gpt` contract and start on `/api/ai/studio-agent-pulse` without inheriting the hidden guided-workflow shell. Pulse mode is state-isolated from Standard mode, exposes an explicit `Deactivate Pulse` control for ending the active Pulse session, and switching or deactivating a Pulse starts a fresh Pulse session. Guided workflows can return step-by-step assistant turns before any final prompt artifact. Voice generation hardcodes the current ElevenLabs defaults (`stability: 0.5`, `similarity_boost: 0.75`, `speed: 1`, `style: 0`, `use_speaker_boost: true`) and `mp3_44100_128` output for both voiceover and voice changer requests. `Sound -> Music` opens a dedicated Music workflow panel with a single main left-column composer, an inline `Standard` / `Custom` switcher, embedded inspiration rails that insert prewritten genre/style prompts into the composer, Auto duration, and authenticated ElevenLabs generation into the Reference Grid audio flow. `Sound -> Sound Effects` opens a dedicated Sound Effects workflow panel with the simplified prompt-first composer, embedded inspiration chips that insert prewritten effect prompts, and footer-only `Loop` plus `Auto` controls. `Libraries -> Characters` opens the embedded Character properties panel, which is the primary character-management host and now lands on `Character Profile` first instead of `Manage Characters`. The inline Expert Edit `Layers` panel now sits in the left rail directly below `Prompt Presets`. Double-clicking image/video/audio references in the Reference Grid or Quick Slot Inventory opens the detail modal, where `Save` persists that media into `All Media` and appears to the left of `Download`. `Libraries -> Media Library` opens a first-class left-panel Media Library tool (`media-library`) with root/custom folders and media+prompt ingestion; `All Media` remains the master folder with root tabs (`All Media`, `Images`, `Videos`, `Prompts`) inside the same folder surface. Media Library panel/runtime now always uses drag-ghost + root right-click ingest + root permanent delete behavior. Per-custom-folder canvas spaces are always enabled, but now follow the same authority split as folder CRUD: non-project surfaces persist via `/api/ai/media-folder-canvas/[folderId]` + `/api/ai/media-folder-canvas/save`, while project routes persist via `GET | PUT /api/projects/[projectId]/media/folders/[folderId]/canvas`. `Libraries -> Elements` opens a first-class left-panel Elements Library tool (`elements`) with a manage-first embedded flow. Hovering a real style tile reveals a destructive `X`delete action with yes/no confirmation; confirmed deletes persist via Supabase-backed preferences. Clicking a real style tile opens an edit modal for`Style`, `Reference Image`, and `Style Prompt`; saves persist via per-user style detail overrides. Active AI Studio video workflows are Kie-only: the model modal surfaces Kie Veo, Kie Kling, Kie Seedance 2, and Kie Seedance 2 Fast lanes.
