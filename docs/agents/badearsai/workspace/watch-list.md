# Badearsai Watch List

Purpose: lightweight working index for Admin Errors signatures Badearsai has resolved with `watch: true`.

Admin Errors status metadata is the live queue source of truth. This file helps Badearsai handle repeated pasted watch items consistently without relying on chat memory.

## How To Use

For each pasted packet:

1. Check exact incident ID status in Admin Errors.
2. Check whether the fingerprint/source/message/provider/model/failure reason matches a watched signature below.
3. If it is the same singleton shape and production evidence still matches the prior rationale, keep or mark it `resolved` with `watch: true`.
4. If the repeat condition is met, promote the cluster back to `real issue`, name the owner lane, and keep the new row open or route it.
