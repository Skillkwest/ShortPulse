# Reference Grid Modularization Evidence

Purpose: canonical evidence index for the AI Studio Reference Grid Foundation Program.

Program doc:
- `docs/planning/ai-studio-reference-grid-modularization-program.md`

Tracker:
- `docs/planning/ai-studio-reference-grid-modularization-tracker.md`

## Folder Map
- `phase-0/`: contract freeze artifacts and baseline behavior/perf captures.
- `phase-1/`: domain core extraction evidence.
- `phase-2/`: ingestion unification evidence.
- `phase-3/`: projection semantics evidence.
- `phase-4/`: media runtime unification evidence.
- `phase-5/`: canvas/state decomposition evidence.
- `phase-6/`: guardrail enforce + cleanup closeout evidence.

## Required Evidence Per Phase
1. Scope summary and in-scope file list.
2. Tests executed and result summary.
3. Perf audit results when phase touches runtime/perf paths.
4. Regression summary and mitigation notes.
5. Rollback readiness statement.
6. Follow-up actions and owner.
7. Post-implementation audit addendum when a phase is marked complete.

## Naming Standard
Use ISO date and phase prefix:
- `YYYY-MM-DD-phase-NN-<topic>.md`

Example:
- `2026-02-23-phase-00-contract-freeze-baseline.md`
- `2026-02-23-phase-02-post-implementation-audit-and-external-benchmark.md`
