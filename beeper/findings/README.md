# Beeper Findings

Purpose: keep the highest-signal product learnings from Beeper runs in one compact workspace folder.

## Use This Folder For

- route-by-route product truth that is still useful after raw evidence is retired
- cross-run synthesis that helps engineering decide what to fix next
- compact indexes that point to the best Beeper reports, checkpoint summaries, and D-Bug handoffs

## Do Not Use This Folder For

- raw screenshots
- raw network captures
- storage-state dumps
- signed Supabase URLs
- auth tokens, refresh tokens, or other sensitive payloads

## Current Index

- `2026-05-23-production-testing-synthesis.md`

## Load Policy

- Load this folder before reopening old run packets when the goal is product understanding rather than historical forensics.
- Only reopen older run notes or evidence manifests when the current lane needs lane-specific repro detail.
