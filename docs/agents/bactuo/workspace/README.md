# Bactuo Workspace

Purpose: define Bactuo's temporary workspace surface for intake packets, scratch notes, transient lane planning, and active generation investigations that should stay separate from canonical docs and retained artifacts.

## Use This Workspace For

- temporary handoff packets
- scratch architecture notes
- draft investigation outlines
- lane-local implementation checklists
- transient checklists for an active generation lane

## Do Not Use This Workspace For

- final source-of-truth contracts
- final architecture plans or backlog-defining planning docs
- durable memory
- retained reports that should live under `docs/records/artifacts/agent/bactuo/`
- secrets, tokens, raw customer data, or environment dumps

Promote anything durable into Bactuo memory, SOP, source map, architecture plan, or retained artifacts once it becomes reusable.

Delete or overwrite workspace material freely once the active lane is complete. This folder is not a historical ledger.

## Canonical Entry Points

- Agent contract: `docs/agents/bactuo/README.md`
- Local instructions: `docs/agents/bactuo/AGENTS.md`
- Repo-visible memory: `docs/agents/bactuo/memory.md`
- Standing SOP: `docs/agents/bactuo/standard-operating-procedure.md`
- Ownership manifest: `docs/agents/bactuo/ownership-manifest.md`
- Source map: `docs/agents/bactuo/generation-recovery-settlement-source-map.md`
- Architecture plan: `docs/agents/bactuo/generation-architecture-consolidation-plan-2026-06-03.md`
- Retained artifacts: `docs/records/artifacts/agent/bactuo/`
