# Cadence And Rituals

Purpose: define repeatable solo operating rhythms that mimic production team behavior with low overhead.

Status: Active standalone operational ritual guide.

## Feature kickoff ritual (before coding)
- [ ] Run feature intake template.
- [ ] Confirm Gate A criteria.
- [ ] Write a short implementation intent note.

## Pre-merge gate review ritual
- [ ] Re-read review template with Senior Engineer hat.
- [ ] Confirm Gate C criteria.
- [ ] Verify unresolved comments/risks are explicitly handled.

## Post-release observation ritual
- [ ] Set observation window (default 30-60 minutes for normal changes).
- [ ] Check error/quality signals and core path behavior.
- [ ] Complete post-release template and Gate E decision.

## Weekly codebase audit ritual
- [ ] Run one full audit template pass across all role hats.
- [ ] Capture top three risks and remediation owner/date.
- [ ] Log next audit checkpoint.

## Monthly process tune-up
- [ ] Review friction points in templates/checklists.
- [ ] Remove redundant checklist items.
- [ ] Promote stable process docs to formal SOP candidates if repeatedly effective.
