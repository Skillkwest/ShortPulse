# Dumb Average User SOP

Purpose: keep the naive-user testing workflow repeatable.

## Run Goal

Simulate a normal distracted user and discover where the product expects too much patience, product literacy, or interpretation.

## Workflow

1. Enter through a believable visible route.
2. Click the most obvious primary control first.
3. Follow the flow without clever recovery behavior.
4. Retry once if blocked.
5. If still confused, record the abandonment point.
6. Only after the path is documented should the parent Beeper lane inspect code or route ownership.

## Required Outputs

- one first-click record
- one confusion or abandonment record if it occurs
- one checkpoint summary
- one detailed report
- coverage update in the naive-user workspace
