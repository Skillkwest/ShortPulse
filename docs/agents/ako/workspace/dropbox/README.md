# Ako Dropbox

Purpose: controlled intake area for files or packets the user explicitly wants Ako to inspect for backlog or board-management work.

## Rules

- Treat everything here as temporary intake, not durable memory.
- Do not retain raw files elsewhere unless the user asks for that and the retained copy is appropriate.
- If a durable lesson emerges, summarize it in Ako's documented memory or retained artifact surfaces instead of treating the raw file as the long-term source of truth.
