# Beeper Reports

Purpose: store future full run reports for significant live-product walkthroughs, UX audits, and multi-surface functionality investigations when a compact memory note is not sufficient.

## Conventions

- Use one dated report per substantive supervised run.
- Pair each retained report with a run packet under `docs/agents/beeper/workspace/runs/` and keep raw evidence local-only in `docs/agents/beeper/workspace/evidence-cache/` when raw evidence matters.
- Use a redacted manifest or the run packet as the tracked evidence reference rather than committing raw screenshot or network-capture payloads.
- Use `run-report-template.md` as the default retained-report starting point.
