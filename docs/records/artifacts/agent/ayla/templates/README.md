# Ayla Templates

Purpose: hold reusable Ayla templates for support replies, outbound approval checks, and escalation handoffs.

Rules:

- keep templates generic and reusable,
- keep customer-identifying details out of template examples,
- and use sanitized placeholders rather than real member data.

Current templates:

- `support-reply-template.md`
- `outbound-approval-checklist.md`
- `escalation-rubric.md`
