# Maya Prompt Bank

Use these as starting points for Maya-style image generation. Adjust naturally during a run.

Maya's prompts should sound like a practical creator trying to make usable short-form assets, not like an internal benchmark.

## Default UGC Project

Project: `Tiny Apartment Reset Kit`

Series: `5-minute reset routines for busy renters`

Maya is making UGC-style assets that feel like something she could use in a real TikTok/Reels post, email opt-in, or product promotion for her meal-planning template. Prompts should be practical and slightly imperfect, not lab-perfect.

### Calm Vertical Cover

```text
Create a calm, realistic vertical social image for my Tiny Apartment Reset Kit series. It should feel like a warm, practical Reel cover about a five-minute after-work reset for busy renters. Small apartment living room or kitchen, natural light, a little lived-in but tidy, realistic details, not luxury, no text in the image.
```

### Meal Planning Template Visual

```text
Create a realistic vertical image for a creator selling a simple meal-planning template. Show a tidy small apartment kitchen counter with a laptop or tablet, a handwritten grocery list, simple ingredients, and soft natural light. It should feel achievable for a busy renter, not luxury or staged. No readable text.
```

### Renter-Friendly Morning Reset

```text
Create a realistic vertical image for a short-form post about a five-minute morning reset in a small rented apartment. Show a calm living room corner with a yoga mat, water glass, folded blanket, and natural morning light. Practical, warm, relatable, no text, not overly polished.
```

### Prompt Iteration Notes

If the first output feels too glossy:

- add "less polished, more lived-in, realistic apartment details"
- add "not luxury, not influencer mansion"

If the first output feels too generic:

- add one specific room or task
- add "small apartment renter context"
- add "practical creator asset for TikTok or Reels"

If the first output includes text:

- add "no text, no lettering, no captions, no words"

## Credit Discipline

Default: one image generation per run unless the scenario explicitly requires a second variant and the visible credit cost is clear.

## Human Prompt Imperfections

Maya may write prompts that need normal creator cleanup:

- too many ideas in one prompt,
- missing `no text` until she remembers,
- vague mood words like "calm" or "practical,"
- overcorrecting after an output feels too glossy,
- changing one thing at a time only when she remembers to slow down.

These imperfections are useful testing signals. The app should still help Maya recover, iterate, save, and find the result.
