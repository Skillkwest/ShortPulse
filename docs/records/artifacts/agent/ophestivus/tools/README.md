# Ophestivus Runtime Tools

Purpose: store the Ophestivus-owned executable helper scripts used by the Ophestivus SOP workflows.

## Notes

- These files are the active Ophestivus runtime helpers.
- `frontend/package.json` provides the supported `npm run ophestivus:*` command wiring.
- Shared validation for these tools may remain under `frontend/scripts/__tests__/` and `frontend/tests/scripts/`.
