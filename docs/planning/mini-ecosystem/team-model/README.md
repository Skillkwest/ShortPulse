# Team Model (Solo Multi-Role)

Purpose: define the professional-role model used by this mini ecosystem.

Status: Working, non-authoritative planning/lab model.

## Roles in this model
- Product
- Engineer
- Senior Engineer
- QA Engineer
- Platform/Release
- Security Reviewer
- Product Design

## Role charter schema (fixed)
Each role file includes:
- Mission
- Owns
- Does not own
- Inputs
- Outputs
- Gate authority (what can be blocked)
- Escalation triggers
- Handoff checklist
