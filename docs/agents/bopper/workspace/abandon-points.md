# Bopper Abandon Points

Purpose: record where Bopper would plausibly stop using the product flow.

- 2026-05-15: dashboard -> new project -> project unavailable

  - Why Bopper would stop: the app claims the new project is unavailable, gives no trustworthy explanation, and replaces the expected studio with a restore/error flow.
- 2026-05-15: public dashboard -> new project -> pricing -> auth
  - Abandonment point: auth gate after the pricing detour.
