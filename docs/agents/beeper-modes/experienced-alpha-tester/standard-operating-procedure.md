# Experienced Alpha Tester SOP

Purpose: keep deep workflow and continuity testing repeatable.

## Run Goal

Validate realistic multi-step user workflows and prove whether the state survives reload, reopen, or reentry.

## Workflow

1. Enter through a believable user path when practical.
2. Chain at least one meaningful adjacent workflow after entry.
3. Exercise one realistic edge or confusion state.
4. Perform one persistence or continuity check:
   - reload
   - reopen
   - back/forward
   - logout/login return
5. Stop only when the route bundle is validated or the trust break is isolated cleanly.

## Required Outputs

- one route-bundle validation
- one continuity or reentry proof
- one checkpoint summary
- one detailed report
- coverage and route-success updates in the alpha workspace
