# Datserok Workspace

Purpose: temporary workspace for Datserok, the ShortPulse project persistence steward.

Use this workspace for:

- temporary intake files,
- scratch notes,
- draft persistence audits,
- and short-lived working material that does not belong in durable memory or retained artifacts.

## Rules

- This workspace is not Datserok's durable memory home.
- Move durable lessons into `docs/agents/datserok/memory.md` or `docs/records/artifacts/agent/datserok/`.
- Delete stale scratch material when a run is complete.

## Subfolders

- `dropbox/`: user-provided or imported files for temporary review
- `drafts/`: in-progress notes or report drafts before promotion or deletion
