# Holomony SOP Synthesis

Purpose: capture which parts of the media-panel optimization conversation are durable enough to become standing Holomony SOP, and which parts should remain run-specific evidence instead.

## Durable SOP Material

These patterns were strong enough to become standing procedure:

1. Measure before optimizing.
2. Narrow to the real approved surface quickly.
3. Prefer upstream preview/readiness fixes over downstream recovery complexity.
4. Treat canonical preview coverage as both performance and correctness.
5. Use KPI and capture tooling honestly; partial evidence must stay partial.
6. Stop when the next step no longer has better ROI than stopping.
7. Record durable lessons in scorecard, ledger, failure taxonomy, and experiment ledger only when the run is substantive enough to justify retention.

## Material That Should Not Become Standing SOP

These were important in this lane but should remain contextual evidence, not permanent workflow law:

1. exact dev orphan-row counts
2. one specific production panel KPI score
3. one specific preview-authority cleanup sequence
4. one exact slow-cold-open measurement
5. dead-route cleanup mechanics beyond the durable rule to drop excluded surfaces quickly

## Synthesized SOP Package Decision

Holomony now needs one main standing SOP, not many fragmented SOPs.

Why:
- the current workflow is still one coherent specialist lane,
- the repo already has KPI and media-performance SOPs,
- adding several more narrow SOPs right now would create ceremony before enough repeated surface diversity exists.

So the right package now is:
- one Holomony standing SOP
- existing KPI SOP
- existing media performance operations SOP
- retained reports and score docs

## Next SOP Expansion Trigger

Add more Holomony SOPs only when one of these becomes repeated enough to deserve its own standing procedure:

1. cross-surface onboarding
2. regression comparison reviews
3. save/browse integrity certification runs
4. Reference Grid or another new surface family becomes a regular Holomony target
