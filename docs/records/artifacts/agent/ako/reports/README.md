# Ako Reports

Purpose: retain dated Ako reports when a backlog audit, board reconciliation, or planning-state review needs more durable detail than the main backlog or run log should carry.

## Typical Report Types

- backlog state audits
- repo-vs-board reconciliation packets
- stale-item review summaries
- planning-readability cleanup summaries

## Rules

- Keep reports dated and scoped.
- Use the canonical backlog for the final active state whenever possible.
- Do not turn this folder into a second source of truth for what is currently open.
