# Badearsai Retained Artifacts

Purpose: retained artifact home for Badearsai, the ShortPulse error manager agent.

This folder stores non-authoritative retained Badearsai artifacts:

- reports,
- run logs,
- training history,
- helper-tool notes,
- safe templates,
- non-sensitive parsed packet summaries.

Authoritative Badearsai operating docs live under `docs/agents/badearsai/`.

## Layout

- `reports/`: dated incident-audit reports, buildout plans, and queue-classification summaries.
- `training-history.md`: supervised-run learning log.
- `run-log.md`: concise chronological run register.
- `templates/`: future reusable report or classification templates.

Do not store secrets, cookies, auth tokens, raw env values, provider credentials, signed URLs, private customer content, payment data, or unsafe raw packet archives here.
