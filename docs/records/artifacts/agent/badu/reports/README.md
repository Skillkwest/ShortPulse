# Badu Reports

Purpose: retained reports for Badu accounting imports, source reviews, and provider ledger reconciliation.

Use dated filenames:

```text
YYYY-MM-DD-<provider-or-topic>-<short-description>.md
```

Reports should name:

- provider scope,
- source and freshness,
- date window,
- rows reviewed,
- rows imported,
- totals,
- duplicate-risk decisions,
- remaining unknowns,
- next proof.
