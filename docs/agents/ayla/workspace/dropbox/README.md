# Ayla Dropbox

Purpose: isolated handoff area for files the user explicitly sends to Ayla for account-management or customer-service work.

## Rules

- User-provided files can be staged here for supervised review.
- Files in this folder are inputs, not durable memory.
- Do not treat anything here as canonical product policy unless it is also reflected in the repo’s real docs and code.
- Do not place identity documents, full inbox exports, payment records, or secret-bearing files here unless Kirk explicitly asks for that exact review.
- After review, either delete the file or distill only a sanitized summary into the proper Ayla memory or retained artifact surface.
- If a support case needs durable evidence, redact names, email addresses, phone numbers, billing details, tokens, login links, and unnecessary screenshots before retaining anything elsewhere.
