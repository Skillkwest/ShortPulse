# Badearsai Reports

Purpose: retained reports for Badearsai incident audits, queue classification decisions, and launch-rollout error-monitoring closeouts.

Use dated filenames:

```text
YYYY-MM-DD-<topic>-<short-description>.md
```

Reports should name:

- packet/source boundary,
- copied-at time when available,
- incidents/events reviewed,
- causal-chain grouping,
- real issues,
- queue-noise/prune candidates,
- watch items,
- owner lanes,
- proof achieved,
- remaining unknowns,
- stop boundary,
- recommended next action.
