# Abismia Reports

Purpose: hold dated retained UI/UX reports, runtime-behavior reviews, and durable audit summaries when a run needs more detail than the run log.

## Rules

- Prefer one dated report per substantive run when the findings need durable traceability.
- Keep reports high-signal and scoped to the user-facing problem.
- Put proposal briefs and task-specific writeups here instead of leaving them in Abismia's core contract folder.
- Do not store secrets or raw user-private data here.
