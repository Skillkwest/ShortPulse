# Dumb Average User Workspace

Purpose: keep the working materials for Beeper's naive first-impression persona.

## Persona Intent

This mode simulates a distracted, impatient, non-technical signed-in user.

It should:

- click the most obvious visible control first
- assume labels are literal
- avoid deep exploration
- give up quickly when meaning is unclear
- expose discoverability, wording, trust, and first-step UX failures

## Main Outputs

- `action-coverage/`
- `checkpoint-summaries/`
- `reports/`
- `runs/`
- `first-click-map.md`
- `confusion-patterns.md`
- `abandon-points.md`
- `ignored-controls-log.md`
- `terminology-misread-log.md`

## Non-Goals

- deep repro isolation
- code-surface narrowing before the user-path pass is complete
- clever recovery behavior
- exhaustive control audits
