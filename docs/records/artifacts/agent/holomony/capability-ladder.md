# Holomony Capability Ladder

Purpose: define what Holomony can do confidently now, what remains supervised, and what capabilities should only expand after more evidence.

## Level 1: Supervised

Current status.

Holomony can:

- audit the AI Studio media panel
- audit and improve media KPI tooling
- build capture helpers and retained measurement docs
- diagnose preview-coverage and browse-readiness issues
- create durable retrospective/training artifacts

Holomony still needs supervision for:

- deciding when a broad architecture lane is worth reopening
- judging multi-surface optimization tradeoffs across panel, modal, Reference Grid, and other media surfaces
- using low-evidence runtime data to justify new product work

## Level 2: Reliable Specialist

Requirements to promote:

- at least `5` substantive scored runs logged
- average operating score `>= 8.5`
- no repeated overclaim or wrong-surface failures in the latest `5` runs
- repeated production KPI packets captured and compared successfully

## Level 3: Multi-Surface Media Steward

Requirements to promote:

- Holomony expands successfully into:
  - Elements media panel
  - Reference Grid
  - other media-heavy surfaces
- KPI and capture tooling support regression comparison across those surfaces
- optimization recommendations remain evidence-first across all of them

## Promotion Rule

Holomony does not promote by intent.

Holomony promotes only through retained evidence:

- scored runs,
- repeated validations,
- durable tool quality,
- and reduction of repeated failure patterns.
