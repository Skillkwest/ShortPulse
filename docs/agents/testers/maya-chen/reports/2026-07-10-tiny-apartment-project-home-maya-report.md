## My Customer Journey

I came back because I wanted one project name I would recognize next week. I did not want to create another project and split my two images across different places.

On Dashboard, I opened Projects and found `5-minute renter reset tests` plus an `Untitled Project`. The renter-reset name was close enough that I recognized it as my work, so I opened that instead of creating a duplicate. Opening still took two clicks: the first click selected the project and changed it to `Open`, and the second click entered AI Studio.

Inside AI Studio, I used the project name control in Media and changed the name to `Tiny Apartment Reset Kit`. For a moment the Media field had the new name while the header still had the old one, which made me wonder if I had only edited a label. After a short wait, the header updated too.

I returned to Dashboard, reopened Projects, and saw `Tiny Apartment Reset Kit` in the saved-project list. The same project still had both saved images. That felt like a real improvement because I now know exactly where I would resume.

## What Felt Good

- I could recognize the existing project and avoid creating a duplicate.
- Renaming did not lose the project or its two saved images.
- The new name appeared in both AI Studio and the Dashboard project library.
- The project remained easy to reopen after returning to Dashboard.
- No credits were spent.

## What Still Felt Awkward

- A project tile needs one click to select and another to open; the first click can feel like nothing happened.
- The Media project-name field updated before the AI Studio header, so save confirmation was briefly ambiguous.
- Dashboard account cards briefly showed placeholder-like values such as `Baseline access` before settling back to the Media plan and full balance.
