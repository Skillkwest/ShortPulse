# Phase 13 Evidence Index

Purpose: capture implementation and validation evidence for the cross-plan master rollout wave execution.

## Required Evidence Artifacts
1. Baseline capture packet before Wave B implementation.
2. One evidence note per wave (`A` through `H`) including:
   - scope,
   - touched surfaces,
   - validation commands run,
   - gate result (`pass/hold/fail`),
   - rollback readiness.
3. Research checkpoint notes listed in `research-checkpoints.md`.
4. Closeout summary linking tracker and decision-log updates.

## Naming Convention
Use:
`YYYY-MM-DD-phase-13-wave-<letter>-<short-slug>.md`

Example:
`2026-03-02-phase-13-wave-b-adaptive-gate-stabilization.md`

## Minimum Validation Fields Per Evidence Note
1. Commands run (exact command text).
2. Key output summary (pass/fail and critical counters).
3. Risk notes and unresolved items.
4. Rollback path (flag, revert, migration fallback).
