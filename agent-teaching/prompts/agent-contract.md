# Agent Contract

Purpose: formalize a mature agent when the SOPs already exist.

Use this only after the workflow is real enough to define clearly.

```text
Create an agent contract from the existing SOPs.

Agent name:
<agent name>

Primary task:
<primary task>

Task surface:
<what this agent owns and what it does not own>

Definition of done:
<what must be true before the task is considered complete>

Authority boundaries:
<what the agent may do without approval and what still requires approval>

Escalation conditions:
<when the agent must stop and ask for human review>
```

## Use It For

- mature recurring workflows
- formal boundaries
- approval rules
- durable onboarding for future runs

## Do Not Use It For

- undefined tasks
- first-pass experimentation
- work that has no stable SOP yet
