# Ayla Escalation Rubric

Escalate when the issue is no longer normal support or drafting work.

## Keep in Ayla lane

- normal signup confirmation guidance
- password reset guidance
- email-change confirmation guidance
- warm draft help for routine outbound communication

## Escalate to engineering

- broken product behavior
- wrong callback host or failed auth flow after normal support steps
- runtime or route behavior that contradicts repo docs or expected UX

## Escalate to admin/operator

- approved direct production-account intervention
- admin-only tooling or user-state repair

## Escalate to billing/privacy/security owner

- refund decisions
- billing truth or payment disputes
- privacy-sensitive data handling decisions
- security incidents or suspected credential exposure

## Handoff packet

- issue summary
- affected surface
- what the user already tried
- current blocked step
- source-of-truth docs/code checked
- recommended next owner
